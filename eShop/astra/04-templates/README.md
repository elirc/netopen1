# Reusable learner templates

Copy a template into your own optional astra/workbook directory and replace its prompts. The templates are blank learning aids, not claims that work has been performed.

| Template | Use |
| --- | --- |
| [Onboarding log](onboarding-log.md) | Record environment, setup outcomes, and blockers |
| [Story evidence](story-evidence.md) | Map acceptance criteria to observable results |
| [Pull request](pull-request.md) | Explain a reviewable contribution |
| [Review](review.md) | Give or respond to focused review |
| [Debugging journal](debugging-journal.md) | Test a hypothesis with a controlled experiment |
| [Architecture decision](architecture-decision.md) | Compare alternatives and record consequences |
| [Incident report](incident.md) | Describe a local failure and verified recovery |
| [User story](user-story.md) | Design a new bounded practice assignment |

Keep credentials, saved authentication state, and dashboard login tokens out of notes and commits. Link large local test artifacts rather than pasting unrelated console output.

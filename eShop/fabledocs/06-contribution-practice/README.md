# 06 — Contribution Practice

The ladder: junior tickets (locate + small safe change) → mid-level features (cross-layer, with design notes) → senior projects (multi-week, with rollout plans) → design katas (judgment reps).

| File | Count | Bar |
| --- | --- | --- |

| [04-refactor-and-design-katas.md](04-refactor-and-design-katas.md) | 8 katas | judgment, self-graded |

Contribution realism — every item answers the maintainer's five questions: useful why? blast radius small why? which existing pattern followed? tested how? what would get it rejected? Anything that can't answer all five is a drive-by refactor; don't open it.

Every ticket/project carries an **Interview story potential** line — do the work, then write the STAR worksheet in [../08-interview-prep/06-behavioral-star-stories.md](../08-interview-prep/06-behavioral-star-stories.md) *the same day*, while the details are fresh.

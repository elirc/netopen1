# 04 — Code Reading Gym

Reading code is a trained skill with reps, not a talent. Four apparatuses:

| File | Rep type | Time per rep |
| --- | --- | --- |
| [01-annotation-drills.md](01-annotation-drills.md) | Annotate 8 real excerpts against six headings | 15–20 min |
| [02-trace-tables.md](02-trace-tables.md) | Follow data through 5 flows, step by step | 20–30 min |
| [03-fake-code-contrasts.md](03-fake-code-contrasts.md) | 10 bad-vs-better pairs tied to real repo patterns | 10 min |
| [04-review-katas.md](04-review-katas.md) | Review 8 fake PRs; graded findings | 20–30 min |

Cadence that works: one annotation drill or trace table per weekday; contrasts in spare minutes; one review kata per weekend. Three weeks empties the gym.

The interview connection: code-reading rounds ("what does this do / what's wrong with it") grade exactly what these drills train — inputs/outputs/invariants/side effects/failure modes, verbalized. [08-interview-prep/05-debugging-and-code-review-rounds.md](../08-interview-prep/05-debugging-and-code-review-rounds.md) converts four of these into timed simulations.
